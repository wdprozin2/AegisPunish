Suíte Corporativa de Moderação

Engine avançada de punições, banimentos, silenciamentos e auditoria projetada para redes Paper, Folia, Velocity e BungeeCord. Desempenho sub-milissegundo com proteção anti-abuso.

⚡ Recursos em Destaque

Desenvolvido para atender desde servidores Survival e RankUP individuais até redes com dezenas de milhares de jogadores simultâneos.

🛑
Injeção no CommandMap
Substitui comandos nativos como /minecraft:ban e atalhos com prioridade máxima, impedindo que staffers ou jogadores burlem punições com prefixos.
⚖️
Hierarquia de Cargos
Integração profunda com o LuckPerms e verificação de jogadores offline. Impede que moderadores punam cargos equivalentes ou superiores.
💾
Armazenamento Dual Engine
Conexão MySQL/MariaDB de alta performance via HikariCP com fallback automático para SQLite local sem perda de dados caso o MySQL caia.
💬
Webhooks Discord com Avatar
Notificações em tempo real com skin 3D, motivos, links de provas, tempo relativo e embed especial rosa para revogações e perdões.
🔄
Migrador Universal
Migração com 1 clique de punições ativas e históricos vindos do LiteBans, AdvancedBan, LeafPunish, EssentialsX e Vanilla.
⬆️
Auto-Updater Modrinth
Verificação automática de novas versões direto no Modrinth com notificação in-game e comando /aegis update com download seguro em segundo plano.

📦 Instalação & Setup

A instalação é extremamente simples e não exige nenhuma dependência externa obrigatória:

  1. Baixe o .jar correspondente à sua plataforma na pasta de downloads ou no Modrinth:
    • Paper / Purpur / Folia / Spigot: AegisPunish-Paper.jar
    • Velocity: AegisPunish-Velocity.jar
    • BungeeCord / Waterfall: AegisPunish-BungeeCord.jar
  2. Coloque o arquivo na pasta plugins/ do servidor.
  3. Inicie ou reinicie o servidor para gerar as configurações padrão em plugins/AegisPunish/config.yml.
  4. (Opcional) Configure os dados do seu banco MySQL. Se não configurar nada, o SQLite local será ativado instantaneamente sem necessidade de configuração adicional.
💡 Dica de Atualização
Você pode usar /aegis update a qualquer momento dentro do servidor para baixar a versão mais estável do Modrinth automaticamente.

💾 Armazenamento Dual Engine (MySQL & SQLite)

O AegisPunish conta com um sistema de tolerância a falhas pioneiro. O pool de conexões é gerenciado pelo HikariCP com índices compostos para leituras e gravações assíncronas.

database:
  # Escolha: 'MySQL' para servidores em rede ou 'SQLite' para local
  type: 'SQLite'
  mysql:
    host: 'localhost'
    port: 3306
    database: 'aegispunish'
    user: 'root'
    password: ''
  pool-settings:
    max-pool-size: 30
    min-idle: 10
    max-lifetime: 1800000
    connection-timeout: 5000

⚖️ Sistema de Hierarquia & Proteção Anti-Abuso

Para evitar abusos onde membros da staff aplicam punições em outros staffers do mesmo cargo ou superiores, o AegisPunish resolve a cadeia de grupos de forma inteligente:

  • LuckPerms: Consulta a hierarquia recursiva do jogador e o peso (weight) de cada grupo herdado.
  • Jogadores Offline: Quando o jogador punido estiver offline, o sistema realiza uma leitura assíncrona na base do LuckPerms via loadUser(UUID).
  • Pesos Personalizados: Permissão direta de peso: aegispunish.weight.<N> (ex: aegispunish.weight.100).
  • Opção prevent-equal-rank: Se ativada, staffers de mesmo peso (ex: dois Ajudantes) não podem punir ou revogar punições um do outro.
hierarchy:
  enabled: true
  prevent-equal-rank: true
  groups:
    dono: 100
    diretor: 90
    administrador: 70
    moderador: 50
    ajudante: 30

📋 Tabela de Comandos & Permissões

Todos os comandos suportam a flag silenciosa -s para não anunciar no chat global.

Comando Permissão Descrição
/punir [jogador] aegispunish.command.punir Abre o menu gráfico interativo (GUI) de punições.
/ban <jogador> [motivo] [-s] aegispunish.command.ban Bane um jogador permanentemente da rede.
/tempban <jogador> <tempo> [motivo] [-s] aegispunish.command.tempban Bane temporariamente (ex: 7d, 12h, 30m).
/ipban <jogador/IP> [motivo] [-s] aegispunish.command.ipban Bane o endereço de IP permanentemente.
/tempipban <jogador/IP> <tempo> [motivo] [-s] aegispunish.command.tempipban Bane temporariamente o endereço de IP.
/mute <jogador> [motivo] [-s] aegispunish.command.mute Silencia o jogador permanentemente no chat.
/tempmute <jogador> <tempo> [motivo] [-s] aegispunish.command.tempmute Silencia o jogador temporariamente.
/warn <jogador> [motivo] [-s] aegispunish.command.warn Aplica um aviso oficial com escada de punição automática.
/kick <jogador> [motivo] [-s] aegispunish.command.kick Expulsa um jogador online do servidor.
/unban <jogador/IP> aegispunish.command.unban Desbane o jogador, limpa cache e envia embed no Discord.
/unmute <jogador> aegispunish.command.unmute Remove o silenciamento de um jogador.
/pardon <id/jogador> aegispunish.command.pardon Revoga qualquer punição ativa universalmente.
/historic <jogador> aegispunish.command.historic Consulta o histórico completo de infrações do jogador.
/aegis update aegispunish.admin Verifica e baixa a versão mais recente do Modrinth.
/aegis reload aegispunish.admin Recarrega configurações, pesos e auto-updater.
/aegis import <fonte> aegispunish.admin Importa dados do LiteBans, AdvancedBan, LeafPunish, etc.

💬 Discord Webhooks & Validação de Provas

Envie logs detalhados diretamente para o canal da sua equipe no Discord:

  • Embeds Estilizados: Inclui render da skin do jogador, operador responsável, escopo do servidor e tempo relativo (<t:TIMESTAMP:R>).
  • Embed de Perdão Especial: Cor magenta/rosa emitida automaticamente ao desbanir ou desmutar.
  • Validação de Links de Provas: Garante que os staffers só anexem provas de domínios confiáveis (YouTube, Imgur, Lightshot, etc.).

🔄 Migrador Universal de Legados

Trocar de plugin nunca foi tão fácil. O AegisPunish importa históricos, banimentos ativos e registros de IP em segundos com um único comando no console ou in-game:

/aegis import litebans     # Importa de LiteBans (SQLite ou MySQL)
/aegis import advancedban  # Importa de AdvancedBan (SQLite ou MySQL)
/aegis import leafpunish   # Importa de LeafPunish (SQLite ou MySQL)
/aegis import essentials   # Importa da pasta plugins/Essentials/userdata/
/aegis import vanilla      # Importa de banned-players.json e banned-ips.json

⬆️ Auto-Updater Integrado

Mantenha seu servidor sempre seguro com as últimas correções:

  • Consulta assíncrona automática à API oficial do Modrinth ao iniciar e periodicamente.
  • Notificação no chat para administradores com permissão aegispunish.admin ao entrarem no servidor caso haja nova versão.
  • O comando /aegis update baixa o novo arquivo direto para plugins/update/, sendo aplicado no próximo reinício sem corromper o arquivo em execução.

👤 Compatibilidade Floodgate (Bedrock) & SkinsRestorer

Em servidores com Geyser e contas piratas, outros plugins costumam falhar ao barrar jogadores banidos. O AegisPunish resolve isso nativamente:

  • Busca Multicamada: Checagem simultânea por UUID, IP e LOWER(target_name) para barrar jogadores Bedrock (prefixos como .Nome) mesmo que o UUID mude.
  • Floodgate API: Renderiza a face correta de jogadores do Bedrock no Discord e nos menus.
  • SkinsRestorer v15: Extrai os hashes de textura SHA-256 para exibir a skin customizada de qualquer jogador.
